Unit 5: Derivatives

Unit 5

Derivatives Live

Eight live games on one host screen. For each derivative, run the story game first (one student per iPad, Kahoot style), then the trading desk (one iPad per group, six rounds, you reveal what happened). Futures: Futures Face-Off (a 15-question warm-up review to open class), The Prom Bus, then The Futures Exchange (half the groups are food makers that buy, half are producers that sell; they hedge wheat, corn, sugar, soybean oil and diesel by trading live with each other under codenames during a timed window, and you pick how many quarters to play; a sealed-bid backup mode is there for slow Wi-Fi. Play in pairs. Commodities open up over the first three quarters, each side gets private clues, headlines drop during trading, and every iPad has a live risk meter). Options: The Sneaker Drop, The Options Floor, then The Options Floor, Part 2 (six stocks with company analysis and an economy report each round, getting harder each round). In both Options Floor games, desks work out their own result after each reveal and see if they got it right. Swaps: The Tip Jar Trade, The Swap Desk. CDS: The Cousin Loan, The Default Desk.

How to run

One page. Works for every game here.

iPad games

  1. Click the game card on the projector computer.
  2. Students go to the address on the card or scan the QR.
  3. They type the game code and their name.
  4. When everyone is on the list, start the game.
  5. Press the big button for each step. Lock, reveal, next.

Projector only

  1. Click the card. No iPads, no codes.
  2. Split the class into teams.
  3. Click through. You tap who got it right.
